# Materiais visuais e evidências

O mapa visual deste projeto está em [docs/knowledge-map.md](../docs/knowledge-map.md), escrito em Mermaid para renderização no GitHub.

As evidências dos experimentos estão no [registro de prompts](../docs/prompts.md): data, seleção de fontes, comandos exatos, trechos curtos, referências e avaliação. Capturas de tela não são necessárias para consultar esse registro.

Esta pasta não contém fotografias de terceiros, capas digitalizadas nem o PDF de *Gifted Hands*. Novos materiais podem ser adicionados quando forem relevantes e houver permissão para publicá-los.
